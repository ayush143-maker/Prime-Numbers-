# Prime-Numbers-

A compact visual experiment built around the question “Do Prime Numbers Have a Pattern?” It presents the topic as an animated browser experience with a play control and a local audio file.

## Preview locally

Open `index.html` in a modern browser, or run a local server:

    python -m http.server 8000

Visit http://localhost:8000.

## Editing the experience

The visualisation is in `index.html`, and `sky.mp3` is the accompanying audio asset. Keep its reference in sync if replacing the file.
